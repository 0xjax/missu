# 诗文内容库

## 范围不是预设篇数

文库先用可靠选本确定价值基线，再用上游知名度决定需要补充多少其他作品：

```text
Rmax = 选本作品中最高的有效常见度排名
N = max(10,000, Rmax)
最终文库 = 排名前 N ∪ 选本并集 ∪ 典籍 ∪ 本地内容
```

一万篇只是初始最低规模，不是目标。先按上式得到候选边界；本次候选边界已接近完整唐宋语料，因此进一步采用完整语料，消除“截断库”与“完整库”的性质差异。这个两阶段判断及当时的数量均写入 `manifest.json`，未来调整选本或语料时必须重新计算，不得沿用旧结论。

无有效排名的选本作品始终保留，但不参与 `Rmax` 计算；其他无排名作品的 `prominence` 为 0。

## 各部分如何组成

- **排名范围**：全唐诗、全宋词按多搜索引擎结果数的对数综合排序，取前 N 篇。词牌别名共享排名，组诗总标题可匹配分首。
- **选本并集**：唐诗三百首、宋词三百首、龙榆生《唐宋名家词选》去重合并。选本与排名范围可能重叠，重复作品只保留一份。
- **选本详情页补充**：选本目录存在、但上游原文库未匹配到的作品，从目录实际详情链接读取原文。先按作者与全文再匹配一次，仍不存在才新增；这些作品属于选本并集，不是另一套无关文库。
- **典籍**：按「作品 → 篇章」组织，不把《论语》各篇拆成独立作品；《诗经》仍保留单篇诗歌入口。《论语三则》属于本地精读，归入「文」，不能替代完整《论语》。章节正文保存在作品内部，阅读页按章排版，搜索覆盖章节正文。
- **扩展原文**：chinese-poetry 与古诗文网全部内容取并集，按作者和规范化全文去重；重复条目合并开放声明的译文、注释与赏析，不另建重复作品。元曲使用 chinese-poetry 的完整子数据集并归入独立「曲」类型；古诗文网条目结合词牌、曲牌与标题体裁标志分类，散文标志包含「志」「传」等。
- **整书来源**：以少量覆盖完整、结构可核验的主源为限。chinese-poetry 提供《论语》《楚辞》《古文观止》、蒙学读本及《纳兰性德诗集》；纳兰性德以该诗集 258 首全量替换其他来源的同作者旧条目，不做新旧正文合并；殆知阁官方维护的 `daizhige-org/daizhigev20` Markdown 版提供四书五经、诸子、史地典籍及《道德经》《资治通鉴》；四大名著与《史记》分别使用完整分回、分篇仓库。《墨子》以子藏本为主，只从道藏本补入《尚贤下》《鲁问》。所有整书均校验预期章数、非空正文和章节 ID；固定版本与每部章数写入 `manifest.json`。不使用禁止抓取的 ctext，也不使用已弃用的维基文库。
- **本地内容**：`works.json` 保存精读内容，`supplemental.json` 保存汉乐府、北朝民歌等上游缺口。

`manifest.json` 自动记录每次构建的来源版本、原始数量、选本匹配、范围与选本交集、详情页补充清单、最终去重数量及数据库哈希。清单与数据库均由脚本生成，禁止手改。

## 核心与完整内容包

同一份最终作品集合生成两个可独立使用的 SQLite，不在运行时跨库拼接：核心库包含全部本地精读与补充内容，加上 `prominence` 最高的 10000 条导入作品，写入 `app/src/main/assets/literature-core.db`；完整库包含核心在内的全部作品，输出 `.local/releases/literature-full.db` 后 gzip 为 `literature-full.db.gz`，同时生成 `literature-manifest.json`。两组清单均记录作品数、字节数与 SHA-256；完整包还记录解压后数据库的大小与哈希。应用内置核心库，完整包上传到与应用版本同名的 GitHub Release，由用户主动下载。收藏与阅读历史使用稳定作品 ID，切换内容包不修改这些用户数据。

## 更新

```powershell
bun install                 # 新机器首次安装内容工具
bun run literature:import   # 更新选本目录、语料与收录范围
bun run literature:build    # 校验、重建数据库与 manifest
```

`import-longyusheng.ts` 负责选本目录，`import-literature.ts` 负责语料匹配和范围计算并生成 `.local/literature/imported-base.json`，`import-expanded.ts` 只从该基础结果生成最终导入数据，避免重复执行继承旧结果；`build-literature.ts` 负责最终数据库。抽样脚本只用于检查漏收，不决定收录边界。
